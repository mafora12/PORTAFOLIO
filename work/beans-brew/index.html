Beans + Brew

A coffee-shop ordering app designed in one week — built so regulars can reorder in a few taps.

My role
Feature map, user flow, UI design and prototype
Team
Solo
Timeline
1 week · 2026
Tools
Figma

The brief

Design the feature map, user flow and screens of a mobile app so Beans + Brew customers can order quickly. The client wanted to encourage repeat purchases, simplify payment, offer pickup or delivery, and make it easy to find what people usually order.

Structure first

Before drawing a single screen I defined the MVP with a feature map and a user flow, so every request from the client had a clear place in the app.

The interface

A friendly, easy-to-scan interface with a calm palette that evokes the warmth of a coffee shop — designed around the client’s goals: reorder your usual, choose pickup or delivery, and pay without friction.

Prototype

A clickable prototype in Figma covering the full ordering flow, from choosing a drink to paying.

Why I like it

How quickly it came together — and how clean and organized the interface turned out.
